# Methods basis and limits

The toolkit applies grounded-theory techniques to inductive process studies. Its source and comparison checks were informed by a methods review. The guidance below describes the scope of that support; it does not validate the agent or claim conformity to one grounded-theory school. Full citations are in [NOTICE.md](../../NOTICE.md).

| Operation | Practical scope |
|---|---|
| Method label | Use “inductive process study using grounded-theory techniques.” The opponent Glaser account is not primary constructivist support; Corbin/Strauss is abstract-only. |
| Episodes and provenance | Sequence/time and source selection/context limits inform reconstruction. REALIZATION_EPISODE, seven epistemic classes and no behavior-to-belief promotion are toolkit design choices. Edited traces omit events; no full trace-ethnography claim without participant observation. Some source support is abstract-only. |
| Coding/translation | Overview-level coding guidance and translation recommendations; language-specific support absent. The operative rule is action-oriented coding, preferring gerunds where they capture process. |
| Comparison | Comparison needs inspectable purpose and consequences. Boeije stages are study-specific, Fram permits comparison outside GT, Glaser stages are lineage-specific. Exact software fields are analyst adaptations. |
| Memos/categories | Birks supports inspectable decisions/interpretive change, not a taxonomy. Version formats are a **single-source proposal**; the toolkit uses four memo types. |
| Sampling | Archive selection can follow conceptual uncertainty but may lack the needed contrasts. Request fields/refusal behavior are a **single-source proposal**; no acquisition authority follows. |
| Negative cases | Examine contrary observations and rivals. The consequence vocabulary is an analyst adaptation, not the sources' exact instrument. |
| Stopping | Code recurrence and meaning development differ; Nelson proposes conceptual depth; information power is abstract-only; interview thresholds do not transfer to archives. No Dey-based stopping rule is implemented. |
| Regime/process proposals | Coverage is thin: regime-comparison design remains a proposal, and its rivals are not yet evidenced. Some source support is abstract-only. A named motor, possible path or product release is not evidence of a transition. No sourced Langley bracketing procedure. |
| Assistance/review | Task/model/corpus-specific results do not validate this agent. In the expert-verification study, all four evaluators were coauthors: author-blinded assessment was not independently staffed. Latent errors, nonrandom bias, missing negatives, shared rationales and single-expert fallibility remain limits. Agreement is not validity. |
| Reporting/governance | Gioia 2013 is abstract-only; the 2018 contributor account distinguishes static data structures from dynamic theory. UNESCO is summary-only. Neither guidance nor a polished diagram grants study, provider or release authority. |

Single sources and overlapping authorship are not independent replications. Abstracts and summaries support only their retained content. The toolkit does not claim a primary constructivist basis, a sourced Langley bracketing procedure or the full Gioia procedure. Use the existing four memo types and action-oriented coding rules; proposed alternatives are not active.

The researcher authorizes inputs and processing and judges analytical interpretations. Software checks establish structure and source bindings; synthetic checks establish software behavior. Neither establishes theoretical saturation or the validity of an explanation.

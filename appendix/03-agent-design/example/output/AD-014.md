# AD-014 · LangGraph persistence

## The record, field by field

- **Mechanism.** Separates thread-state checkpoints from cross-thread application data stored in a store.
- **Evidence.** Official documentation distinguishes the two interfaces and warns that in-memory savers do not survive process restart.
- **Limitations.** Restart durability depends on the backing store and configuration. Checkpoints do not make arbitrary external effects atomic or establish analysis validity.
- **Possible use in TextData (a design interpretation, not an observed result).** Keep execution position separate from the enduring study evidence and decisions.
- **Question an evaluation would have to answer.** Interrupt a task and check both correct resumption and absence of duplicated external effects.
- **Evidence basis.** Selected primary text
- **Reading scope.** The entry draws on selected original text; this does not establish that every referenced work was read in full.
- **Implementation status.** Not executed or benchmarked for this database.

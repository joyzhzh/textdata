# Novelty measurement design

Specify the object, reference universe, evaluator and time before choosing a method. The catalogue covers human, conventional computational and LLM-assisted approaches. Applicability and validation remain unassessed.

## Questions

1. What does novelty mean in each application, and which nearby constructs must remain distinct?
2. What object is being assessed, and what information about it does the assessor actually observe?
3. Relative to which prior objects, knowledge, audience and historical moment is the object novel?
4. Which measurement mechanisms exist, including human, classical computational and LLM assisted approaches?
5. What evidence supports each method for the claimed task, language, population and comparison set?
6. What breaks under paraphrase, changing references, domain transfer, imperfect retrieval, temporal leakage, evaluator disagreement or strategic submissions?
7. What measurement workflow is justified now, what remains exploratory, and what future validation would resolve the uncertainty?

The extraction unit is a **construct–object–application–reference universe–method–validation combination**. Papers are sources for those combinations. Reusing a paper, dataset or human-label set does not create independent corroboration.

## The measurement contract

Every usable measure must answer **novel what, relative to what, for whom, and as of when**. Record these separately:

| Dimension | Required distinctions |
|---|---|
| Object | Idea, component, relation, claim, method, artifact, process, organization, collection or knowledge contribution |
| Observed input | Actual text artifact; description or synopsis of an artifact; evaluator commentary; image, audio, code or structured representation |
| Comparator | The self, team, firm, market, disciplinary literature, historical archive, current submission pool or a specified audience's prior exposure |
| Target | First appearance, distance, atypicality, uncommon combination, meaningful contribution, perceived newness or incremental information |
| Evaluator | Experts, consumers, creators, investors, teachers, affected communities or a specified LLM configuration |
| Time | Object creation, first disclosure, public availability, reference window, model knowledge and judgment date |
| Aggregation | Feature, relation, item, mean, maximum, portfolio diversity or population distribution |
| Intended decision | Descriptive research, empirical explanatory variable, human-review triage, idea screening or comparative evaluation |

Do not collapse novelty, quality, usefulness, feasibility, coherence, surprise, impact and success into one score without a stated construct model. An unusual object can be useless. A valuable innovation can be new to a firm without being historically original. A diverse collection can consist of individually familiar ideas. These are candidate interpretive distinctions to enforce in extraction and validation, not universal score axioms.

## Methods and applications

The catalogue connects 14 method families with 35 application settings. Its 490 pairs are unassessed and unsearched. A representation can be one component of a workflow; it is not automatically an end-to-end measure. Consult the linked research questions for subareas and failure cases.

A proposed product-description workflow would extract stated functions, represent them, compare them with a bounded earlier corpus and test the interpretation against independent judgments. The workflow, agent skill and empirical evaluation remain proposed.

## Methodological entry points

These are starting references, not validated recommendations for every domain.

- [Measuring the market newness of new ventures](https://doi.org/10.1016/j.jbusvent.2010.12.001): venture-market measurement.
- [AI-based novelty detection in crowdsourced idea spaces](https://doi.org/10.1080/14479338.2023.2215740): crowdsourcing and reference sets; online 2023, issue 2024.
- [Generative artificial intelligence, human creativity, and art](https://doi.org/10.1093/pnasnexus/pgae052): content and visual novelty.
- [Literature-Grounded Novelty Assessment of Scientific Ideas](https://arxiv.org/abs/2506.22026v1): retrieval-based assessment; June 2025 preprint.
- [Automating creativity assessment with SemDis](https://doi.org/10.3758/s13428-020-01453-w): task-specific creativity scoring; online 2020, issue 2021.
- [Metrics for measuring ideation effectiveness](https://doi.org/10.1016/S0142-694X(02)00034-0): engineering-design measurement; abstract-level reference.
- [Oslo Manual: the object method](https://www.oecd.org/en/publications/oslo-manual-2018_9789264304604-en/full-report/component-17.html): official firm/market and object-level distinctions, not validation of an LLM scorer.

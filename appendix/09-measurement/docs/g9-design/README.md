# Novelty measurement design

These project-authored inputs support the working catalogue. They describe measurement choices and proposed validation, with no empirical novelty scores.

| File | Contents |
|---|---|
| `METHOD_FAMILIES.json` | 14 method families |
| `APPLICATION_COVERAGE.csv` | 35 application settings |
| `LANES.jsonl` | 61 research questions, with subareas, failure cases and planned outputs |
| `MISSIONS.json` | 12 research areas grouping the questions |
| `METHOD_APPLICABILITY.csv` | 490 unassessed application–method pairs |
| `REGISTRY_CONTRACTS.json` | Six empty schemas for future reference records |

Start with [the measurement design](CAMPAIGN_DESIGN.md) and [extraction and validation guidance](EXTRACTION_AND_VALIDATION.md). [Research areas](MISSIONS.md) provides an index; [search guidance](SEARCH_PROTOCOL.md) supplies terminology and source distinctions for future work. Stable record IDs connect the files and catalogue.

APP05, “Products and functional concepts,” is the product-description illustration. Its specification is unpopulated. The searchable catalogue presents these design resources; it does not establish literature completeness or recommend a method.

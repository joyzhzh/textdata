## Limits

A profile is dated; it is not a promise that the source still looks like this. Recheck the provider's pages before acquisition.

Source-specific limits:

- GPT-4o labels are model outputs, not human ground truth. The README's three-utterance selection wording needs reconciliation with the paper/actual records before sampling.
- Only public WildChat material is released; do not assume access to every source used in the paper.
- README still marks analysis/data-generation code as TODO. Conversation endings do not establish stopping reasons; logs do not show copied text, external editing, attention or actual workplace roles.

## The review's decision on this source

Decision (2026-10-11): Observational complement to controlled CoAuthor; labels, filtering and missing analysis code need validation.

Proposed first task (not executed): Recode user requests and revisions using a human-checked event dictionary; compare inferred collaboration patterns before and after correcting labels and selection.

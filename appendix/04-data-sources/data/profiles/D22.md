## Unit of analysis

Occupation-specific task statements and aggregate ratings, linked to skills, work activities and work context.

## Coverage and dates

Release: Production version 31.0, August 2026; prior versions remain in the release archive. Pin 31.0 rather than a mutable current-data endpoint.

Time: Release versions and field-update dates; a quarterly release is not a repeated survey of every occupation. Avoid interpreting asynchronous updates as real work change.

Size: 31.0 lists 18,838 task statements and 165,780 task-rating rows; ratings cover 911 occupations. Occupation-data table has 1,016 rows, which is a different coverage denominator.

## Content: fields and the identifiers that link records

O*NET-SOC code + Task ID link statements and ratings; task type, source and update date; ratings include scale/category, value, N, uncertainty and suppression flags. Tasks-to-DWA maps provide a further work-activity join.

## Limits

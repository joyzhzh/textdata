## Limits

A profile is dated; it is not a promise that the source still looks like this. Recheck the provider's pages before acquisition.

Source-specific limits:

- Suggestion display does not prove attention, comprehension or a change in private criteria; session termination does not explain stopping motives.
- Crowd writing with 2022-era systems does not establish contemporary workplace coordination, durable skill or multi-agent authority.
- Do not silently equate the interface software release with the original dataset or use derivative-repository licenses as source-data permission.

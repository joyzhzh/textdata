## Unit of analysis

Regulatory/public-notice documents, their agency associations and separately coded obligations/events.

## Coverage and dates

Release: Continuously updated API; published documents from 1994, public-inspection documents from November 2011. Freeze a dated query, identifiers and official source versions for any new dataset.

Time: Publication, effective, comment and action dates are different. Date presence and legal status need document-level checking.

Size: No fixed study count obtained. API pagination returns only the first 2,000 results; partition queries by dates rather than assuming that a single broad query is complete.

## Content: fields and the identifiers that link records

Document number, publication date, document type, issuing agencies, title and full-text/PDF references; docket/RIN links where present. Issuing agency is not automatically the implementing actor.

## Access and reuse

Access: public access; government-content reuse with exclusions

Route: Official JSON/CSV API and document pages; use the linked official PDF/govinfo text when legal wording matters.

Authentication: No API key required; no records downloaded.

What the review inspected: Official developer documentation and Library of Congress rights statement inspected.

Reuse status: government public-domain component; inspect exceptions

Reuse terms: US government content is generally public domain; reprinted third-party copyrighted material can be an exception. NARA/OFR seals are not freely reusable. Do not blanket-license every attachment.

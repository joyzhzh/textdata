## Access and reuse

Access: public access; explicitly licensed database

Route: Official API and documented bulk export route; bounded API retrieval would suit a later small demo.

Authentication: Reads do not require authentication; official docs require a custom User-Agent. No data records acquired.

What the review inspected: Official API and rights documentation inspected; the main data page did not render in the browser.

Reuse status: explicit, component-specific

Reuse terms: Database: ODbL; individual database contents: DbCL; images: CC BY-SA. Preserve attribution and applicable share-alike obligations. Third-party label artwork/content can have additional rights; do not assume one license covers every component.
